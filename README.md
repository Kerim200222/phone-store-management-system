# Phone Store Management System (Telefon Mağazası ve Teknik Servis Yönetim Sistemi)

Antigravity çerçevesi üzerinde C#, C++ ve HTML teknolojileri kullanılarak geliştirilmiş; telefon mağazaları için stok, IMEI takibi, satış (POS) ve teknik servis yönetim sistemidir.

## 🚀 Özellikler

- **IMEI Takibi**: Her telefonun benzersiz IMEI numarası ile hatasız stok ve satış takibi.
- **Hızlı Satış (POS)**: Barkod okuyucu entegrasyonu ve HTML tabanlı hızlı kasa arayüzü.
- **Teknik Servis Yönetimi**: Cihaz kabulü, arıza tespiti, durum güncellemesi ve yedek parça düşümü.
- **Müşteri ve Tedarikçi Yönetimi**: Veresiye/borç-alacak takibi ve cari hesaplar.
- **Fatura ve Fiş Basımı**: Termal yazıcılar için C++ ve HTML destekli yazdırılabilir çıktı.

## 🛠️ Kullanılan Teknolojiler

- **Frontend**: HTML5, CSS3, JavaScript (Antigravity UI Container)
- **Backend / İş Mantığı**: C# (.NET)
- **Donanım & Performans Katmanı**: C++ (Barkod okuyucu ve yazıcı P/Invoke entegrasyonu)
- **Veritabanı**: SQLite (Offline-First / Yerel veritabanı)
